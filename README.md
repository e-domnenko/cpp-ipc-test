# cpp-ipc-test

Демонстраційний проєкт міжпроцесної взаємодії (IPC) на C++: пара процесів `IPC_Producer` та `IPC_Consumer` обмінюються повідомленнями через POSIX shared memory з кільцевим буфером поверх неї.

## Збірка

Використовуються CMake-пресети з [CMakePresets.json](CMakePresets.json): `Debug`, `Release`, `RelWithDebInfo`. Наприклад:

```bash
cmake --preset Release
cmake --build --preset Release
```

Виконувані файли з’являться у `out/build/<preset>/IPC_Producer/` та `out/build/<preset>/IPC_Consumer/`.

## Запуск

Порядок важливий: спочатку запустіть продюсер (він створює сегмент спільної пам’яті), потім споживач.

```bash
./out/build/Release/IPC_Producer/IPC_Producer [розмір_повідомлення]
./out/build/Release/IPC_Consumer/IPC_Consumer
```

Аргумент `розмір_повідомлення` (у байтах) необов’язковий, за замовчуванням — `256`.

## Керування

Однакове для обох процесів:

- **`q`** — коректний вихід.
- **Будь-яка інша клавіша** — пауза / відновлення роботи. У консоль виводиться повідомлення про зміну стану.

## Поведінка при виході продюсера

Якщо продюсер завершується (через `q` або іншим чином), споживач вичитує решту даних з кільцевого буфера та переходить у стан очікування нових повідомлень — і чекає в ньому невизначено довго. Щоб зупинити споживач, натисніть `q`.
